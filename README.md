# Python Projects

This repository contains a collection of Python projects I built while learning programming through coursework and practice.

## Projects
### Furious Flying Fish
An interactive projectile-based game built using object-oriented design. It includes physics-based motion, collision detection, and basic game state management.

### Caesar Cipher
A program that supports encryption, decryption, and frequency-based cracking of Caesar ciphers.

### Food Recommender
A data-processing program that reads restaurant data and filters results based on preferences such as distance, cuisine, and endorsements.

### Podcast App
A program that fetches and parses podcast RSS feeds, extracting structured episode data.

## What I Focused On
- Building clean and readable Python code
- Understanding object-oriented design
- Working with data (files, lists, dictionaries)
- Writing small programs that actually run end-to-end
